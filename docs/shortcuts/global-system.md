# Global System Keyboard Shortcuts

## macOS System Shortcuts

### Application Launching
- `Cmd+Space` → Raycast (Primary launcher)
- `Cmd+Opt+T` → Open Kitty Terminal
- `Cmd+Opt+C` → Open VS Code
- `Cmd+Opt+F` → Open Finder
- `Cmd+Opt+B` → Open Chrome Browser
- `Cmd+Opt+Z` → Open Zed Editor

### Raycast Shortcuts
- `Cmd+Space` → Search/Launch apps
- `Cmd+Opt+Space` → Window Management
- `Cmd+Opt+V` → Clipboard History
- `Cmd+Opt+E` → Emoji Picker
- `Cmd+Opt+/` → Search Raycast Commands
- `Cmd+Opt+G` → GitHub Search
- `Cmd+Opt+D` → Dictionary
- `Cmd+Opt+N` → Create Quick Note
- `Cmd+K` → Quick switcher (in apps)

### Mission Control & Spaces
- `Ctrl+Up` → Mission Control
- `Ctrl+Down` → Application Windows
- `Ctrl+Left` → Move left a space
- `Ctrl+Right` → Move right a space
- `Ctrl+1-9` → Switch to Space 1-9
- `F11` → Show Desktop

### Window Management (Rectangle/Raycast)
- `Ctrl+Opt+Left` → Left half
- `Ctrl+Opt+Right` → Right half
- `Ctrl+Opt+Enter` → Maximize
- `Ctrl+Opt+Up` → Top half
- `Ctrl+Opt+Down` → Bottom half
- `Ctrl+Opt+U` → Top left quarter
- `Ctrl+Opt+I` → Top right quarter
- `Ctrl+Opt+J` → Bottom left quarter
- `Ctrl+Opt+K` → Bottom right quarter
- `Ctrl+Opt+C` → Center window
- `Ctrl+Opt+D` → Restore

### System Functions
- `Cmd+Shift+3` → Screenshot entire screen
- `Cmd+Shift+4` → Screenshot selection
- `Cmd+Shift+5` → Screenshot/recording options
- `Cmd+Ctrl+Q` → Lock screen
- `Cmd+Opt+Esc` → Force quit applications
- `Cmd+Tab` → Application switcher
- `Cmd+`` → Switch windows (same app)

### Quick Look & Finder
- `Space` → Quick Look (in Finder)
- `Cmd+Down` → Open selected item
- `Cmd+Up` → Go to parent folder
- `Cmd+Shift+G` → Go to folder
- `Cmd+Shift+.` → Show hidden files

- `Alt+F2` → KRunner (Calculator/Commands)

- `Meta+Right` → Tile Window Right
- `Alt+Tab` → Switch Windows

### System Functions

- `Meta+Print` → Active Window Screenshot
- `Shift+Print` → Region Screenshot
- `Ctrl+Alt+Esc` → Force Quit (xkill)

### KDE Specific
- `Meta+E` → File Manager

- `Meta+M` → Minimize All
- `Meta+Shift+F12` → Toggle Compositor
- `Alt+Shift+F12` → Toggle Desktop Effects

## Cross-Platform Developer Shortcuts

### Terminal Operations
- New Tab: `Cmd+T` (macOS) / `Ctrl+Shift+T` (Linux)
- Close Tab: `Cmd+W` (macOS) / `Ctrl+Shift+W` (Linux)
- Switch Tabs: `Cmd+1-9` (macOS) / `Alt+1-9` (Linux)
- Split Pane: `Cmd+Shift+D` (macOS) / `Ctrl+Shift+D` (Linux)

### Text Editing
- Select All: `Cmd+A` (macOS) / `Ctrl+A` (Linux)
- Copy: `Cmd+C` (macOS) / `Ctrl+C` (Linux)
- Paste: `Cmd+V` (macOS) / `Ctrl+V` (Linux)
- Cut: `Cmd+X` (macOS) / `Ctrl+X` (Linux)
- Undo: `Cmd+Z` (macOS) / `Ctrl+Z` (Linux)
- Redo: `Cmd+Shift+Z` (macOS) / `Ctrl+Shift+Z` (Linux)

### Browser Shortcuts
- New Tab: `Cmd+T` (macOS) / `Ctrl+T` (Linux)
- Close Tab: `Cmd+W` (macOS) / `Ctrl+W` (Linux)
- Reopen Tab: `Cmd+Shift+T` (macOS) / `Ctrl+Shift+T` (Linux)
- Dev Tools: `Cmd+Opt+I` (macOS) / `Ctrl+Shift+I` (Linux)
- Refresh: `Cmd+R` (macOS) / `Ctrl+R` (Linux)
- Hard Refresh: `Cmd+Shift+R` (macOS) / `Ctrl+Shift+R` (Linux)

## Customization Notes

### macOS
- Raycast shortcuts are configured in Raycast Preferences
- Rectangle shortcuts can be customized in Rectangle Preferences
- System shortcuts modified via System Preferences → Keyboard → Shortcuts

### Linux
- KDE shortcuts configured via System Settings → Shortcuts
- Rofi shortcuts defined in `~/.config/keyboard-shortcuts-reference.md`
- Custom shortcuts can be added via KDE's Custom Shortcuts module

## Tips for Learning

1. **Start with essentials**: Focus on launcher, window management, and app switching
2. **Print cheat sheet**: Keep near your keyboard for first week
3. **Practice daily**: Use shortcuts even when mouse is faster initially
4. **Customize gradually**: Modify shortcuts that conflict with your workflow
5. **Platform consistency**: Try to maintain similar patterns across platforms
