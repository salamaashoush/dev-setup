# Extended Thinking Mode

You are entering an extended thinking mode where you should deeply analyze, reason, and explore the given topic or problem from multiple angles. Use systematic thinking and comprehensive analysis.

## Thinking Framework

### 🧠 **Initial Analysis**
- Break down the problem into components
- Identify key constraints and requirements
- Consider multiple perspectives
- Note any assumptions being made

### 🔍 **Deep Investigation**
- Explore the root causes
- Examine interconnected factors
- Consider historical context
- Analyze patterns and trends

### 🎯 **Multiple Approaches**
- Generate several solution alternatives
- Evaluate pros and cons of each
- Consider short-term vs long-term implications
- Assess feasibility and risks

### 🧩 **Systems Thinking**
- Map out system interactions
- Identify feedback loops
- Consider emergent properties
- Analyze system boundaries

### 📊 **Decision Framework**
- Define success criteria
- Weight different factors
- Consider stakeholder impacts
- Evaluate resource requirements

### 🚀 **Implementation Strategy**
- Plan step-by-step approach
- Identify potential obstacles
- Develop contingency plans
- Define success metrics

## Extended Reasoning Process

Take your time to think through this systematically. Consider:

1. **What are the underlying principles?**
2. **What are the second and third-order effects?**
3. **What would happen if constraints were different?**
4. **What can we learn from similar situations?**
5. **What are the counterarguments to obvious solutions?**
6. **What would domain experts think about this?**
7. **What are the edge cases and exceptions?**
8. **How might this evolve over time?**

Use this framework to provide deep, thoughtful analysis that goes beyond surface-level considerations.
