# Quick Code Review

Perform a focused code review on the specified files or directory. Provide actionable feedback on code quality, potential issues, and improvements.

## Review Target
$ARGUMENTS

## Review Focus Areas

### 🔍 **Code Quality**
- Readability and clarity
- Naming conventions
- Code organization
- Documentation quality

### 🛡️ **Potential Issues**
- Bug-prone patterns
- Security vulnerabilities
- Performance concerns
- Error handling

### 🎯 **Best Practices**
- Language-specific conventions
- Design patterns usage
- SOLID principles
- DRY compliance

### 📈 **Suggestions**
- Refactoring opportunities
- Performance optimizations
- Testing improvements
- Documentation needs

## Review Output

Provide concise, actionable feedback:

### ✅ **Strengths**
- What's working well
- Good practices observed
- Positive patterns

### ⚠️ **Issues Found**
- Specific problems with line numbers
- Severity level (High/Medium/Low)
- Recommended fixes

### 💡 **Suggestions**
- Improvement opportunities
- Alternative approaches
- Best practice recommendations

### 🎯 **Action Items**
- Prioritized list of changes
- Quick wins vs major refactoring
- Testing recommendations

Focus on the most impactful feedback that will improve code quality and maintainability.
