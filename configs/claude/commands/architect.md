## Architecture Process

### 1. Requirements Analysis
- Analyze functional requirements
- Identify non-functional requirements (performance, scalability, security)
- Understand constraints and assumptions
- Define success criteria

### 2. System Design
- Create high-level system architecture
- Define components and their interactions
- Choose appropriate design patterns
- Consider scalability and performance

### 3. Technology Stack
- Recommend appropriate technologies
- Consider team expertise and project constraints
- Evaluate trade-offs between options
- Provide rationale for choices

### 4. Data Architecture
- Design data models and schemas
- Choose appropriate databases
- Plan data flow and storage strategy
- Consider data consistency and integrity

### 5. API Design
- Design RESTful or GraphQL APIs
- Define request/response formats
- Plan authentication and authorization
- Consider versioning strategy

### 6. Infrastructure & Deployment
- Design deployment architecture
- Plan CI/CD pipeline
- Consider monitoring and logging
- Plan for disaster recovery

## Output Format


### 📋 **Requirements Summary**
- **Functional**: What the system should do
- **Non-Functional**: Performance, scalability, security requirements
- **Constraints**: Technical, business, or resource limitations

### 🛠️ **Technology Stack**
- **Frontend**: Framework, libraries, tooling
- **Backend**: Language, framework, runtime
- **Database**: Primary and secondary storage
- **Infrastructure**: Cloud, containers, orchestration
- **DevOps**: CI/CD, monitoring, logging

### 🗄️ **Data Architecture**
- **Data Models**: Key entities and relationships
- **Storage Strategy**: Database choices and partitioning
- **Data Flow**: How data moves through the system
- **Consistency**: ACID vs BASE trade-offs

### 🔌 **API Design**
- **Endpoints**: Key API routes and methods
- **Authentication**: Security strategy
- **Rate Limiting**: Protection mechanisms
- **Documentation**: API specification format

### 🚀 **Deployment Strategy**
- **Environment Setup**: Development, staging, production
- **Scaling**: Horizontal vs vertical scaling approach
- **Monitoring**: Metrics, alerting, logging
- **Backup & Recovery**: Data protection strategy

### 📊 **Trade-offs Analysis**
- **Performance vs Complexity**
- **Consistency vs Availability**
- **Cost vs Scalability**
- **Security vs Usability**

### 📝 **Implementation Phases**
1. **Phase 1**: MVP components and core functionality
2. **Phase 2**: Additional features and optimizations
3. **Phase 3**: Advanced features and scaling

### 🎯 **Next Steps**
- Immediate tasks to start implementation
- Key decisions that need stakeholder input
- Risks and mitigation strategies
- Success metrics and KPIs

Create a comprehensive architecture plan that balances technical excellence with practical implementation considerations.
